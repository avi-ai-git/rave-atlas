How to use this — models, thinking & effort

Each phase tells you which model to run, whether thinking is on, and the effort level. In Claude Code, switch the model with a slash command and turn on thinking by typing the keyword at the start of your message before you paste the prompt.

/model sonnet  ·  /model opus   |   start your message with: think  ·  think harder  ·  ultrathink

Effort scale (the reasoning budget you spend):

Effort: Low = no thinking Effort: Medium = think Effort: High = think harder Effort: Max = ultrathink

Model logic — Sonnet handles scaffolding, API wrappers and CRUD (well-defined work where thinking changes nothing). Opus is reserved for user-visible quality (prompts, set-list creativity) and the one critical orchestration file (the agent graph), where a wrong call breaks everything downstream. This keeps the build fast and cheap without losing marks on the parts that matter.

Start command (paste once at the very beginning, in your empty repo from GitHub):

Read every file in this repository and the file Sprint3_Architecture_Berlin_Music_Agent.md if present. We are building "Rave Atlas", a Streamlit AI agent for Berlin's electronic music scene using a LangGraph ReAct agent over multiple tools. Stack: Streamlit, LangGraph + LangChain, ChromaDB with local sentence-transformers, OpenRouter (OpenAI-compatible, multi-model), SQLite for memory. I will give you one build phase at a time. After each phase, run its test block and show me the full output before finishing. Do not build ahead of the current phase. Confirm you understand and wait for Phase 0.

Streamlit gives you a clean UI for free, so design is light here. Use these only if you want a stronger portfolio look. Run them with your canvas-design skill or as standalone briefs.

1 · Theme

Design a dark, late-night "Berlin after dark" Streamlit theme as a .streamlit/config.toml: a near-black base, a single electric accent colour (suggest one that reads as nightlife but stays high-contrast and accessible), readable body text, and a comfortable font. Give me the exact config.toml values plus the WCAG contrast ratios for text on background.

2 · Hero / logo

Design a simple, original wordmark and small hero banner for "Rave Atlas", an AI agent for Berlin's electronic music scene. Minimal, club-poster influenced, no copying any existing brand or artist. Deliver as an SVG I can drop at the top of a Streamlit app.

Build order is dependency-correct: each phase only needs files from earlier phases. Commit after every phase — full git history is a graded signal in Sprint 3.
