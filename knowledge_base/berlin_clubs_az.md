# Berlin Clubs A-Z — Official City Registry

## Key facts about this list

- The Berlin Senate maintains this as the official registered club database
- Clubs must register to appear; some very small or temporary venues do not
- Registration does not mean RA coverage; many registered clubs have little or no RA presence
- The list covers both underground electronic venues and mainstream or genre-specific clubs (Latin, gay, hip hop)
- Use this as a starting reference; then go to each venue's own website for current programming
- RA covers roughly 40-60% of this list with consistent event listings; the remainder requires direct website or Instagram checking
